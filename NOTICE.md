# Notice

The NetEase Cloud Music client (`NeteaseApi`) follows the approach of **DangoMusic** by Sorihiko
(https://github.com/Sorihiko/DangoMusic, GPL-3.0): the same public web endpoints, the MUSIC_U login cookie, QR login,
MP3-only playback decoded by jlayer and played through OpenAL. Because of that this mod is released under the
GNU General Public License v3.0 or later.

This project is not affiliated with NetEase. It uses unofficial web endpoints that can change or be blocked at any time.
